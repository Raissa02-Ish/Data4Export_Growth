# NDABAGA: Rwanda Export Dashboard

This WebApp is an interactive Shiny dashboard designed to visualize Rwanda’s trade dynamics across years and quarters.  
It highlights top export destinations, key products, and comparative trade trends using Highcharts and bs4Dash.  

# COMPONENTS OF THE APP

This App has: 
> Overview page with Quick summaries and External Trade trending Headline in Rwanda.
> Analytical Dashboard with many interactive visuals showing how Rwanda export is.
> Next Opportunity Page shows the forecasted growth in export using both machine learning and statistical models, such as Prophet and Regresion model.
> Forex-Converter which scrapes real-time exchange rates from BNR and use them in a forex-exchange calcultor.
> Market-Linker, which links SMEs and Farmers with Exporters who reaches foreing markets.

# HOW TO USE IT

> Users can explore quarterly and annual data, supported by insights from the National Institute of Statistics of Rwanda (NISR) and Ministry of Finance and Economic Planning (MINECOFIN).
> Former and SME owners can use Market-Linker platform, we developed to findout where they can trade their goods and agents which can assist to reach markets abroad.
> People in diaspora and other people abroad can see which trade ship different goods from Rwanda so that they may connect.
> User can use our Forex-Converter to know how foreign currencies are being exchanged with real-time rate we get from the National Bank of Rwanda (BNR).

# AIM OF THE APP

The app aims to simplify data-driven decision-making for policymakers, researchers, and analysts.  
Features include dynamic year–quarter selection, responsive charts, and contextual tooltips.  

#DEVELOPMENT

This WebApp has been developed in R using Shiny, dplyr, and highcharter for efficient data visualization., CSS & HTML tools and JavaScript tools.
